fix: register the prompt section per agent so preset compositions keep it (0.9.0)

Preset-bound agents (agent-preset-registry -> select/mount) assemble their
system prompt inside a group mounted from the preset's plugin whitelist,
which drops app-level sections: the callback still ran (the debug log
looked healthy) while the injected text never reached the model, for main
agents and sub-agents alike.

The section now registers on each agent's own composition context via
agent/created, with a bootstrap pass over agents.list() for agents that
predate the plugin load and disposal on agent/disposed — the same path the
official agent-team sections take. Service, state file and RPC route stay
app-level; the app-level section registration is gone.
